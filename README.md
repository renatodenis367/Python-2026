# Python Fundamentals — Data Technician Bootcamp (Week 6)

## Project Overview
This repository contains a collection of Python programming exercises completed during **Week 6 of a Data Technician Bootcamp**. The project focuses on building foundational Python programming skills, ranging from basic syntax and user interaction to algorithmic logic and mathematical calculations. All exercises were completed and tested using **Google Colab** and **Jupyter Notebooks**.

## Tools & Technologies
- **Python 3**
- **Google Colab / Jupyter Notebooks**
- **Pandas** *(introductory data manipulation)*

---

## Core Skills Demonstrated

### 1. Variables, Print, and Input
- Declared and assigned variables to store data.
- Used `print()` to output results and `input()` to capture user data.
- Utilized **type casting** (e.g., `int()`, `float()`) to convert user input strings into numerical values for calculations.

### 2. Conditional Logic
- Used `if`, `elif`, and `else` statements to control the flow of programs.
- Applied comparison operators (e.g., `==`, `>`, `%`) to evaluate conditions and make decisions.

### 3. Loops
- Utilized `for` loops to iterate through sequences (like lists and ranges).
- Implemented `while` loops for continuous execution until a specific condition was met (e.g., menu systems).

### 4. Functions
- Created reusable blocks of code using `def` to perform specific tasks, reducing repetition.

---

## Practical Applications

### Building Logic & Algorithms
- **FizzBuzz:** Implemented a classic interview algorithm using a `for` loop through numbers 1 to 100, utilizing `if/elif/else` statements and the modulo operator (`%`) to check divisibility by 3 and 5.
- **Palindrome Checker:** Developed logic to reverse strings and compare them to the original.
- **Prime Number Checker:** Used loops and conditional logic to determine if a number has any divisors other than 1 and itself.

### Performing Calculations
- Created programs to calculate the **area of a rectangle**, convert **Celsius to Fahrenheit**, and compute **compound interest**.
- Built a program to convert a given number of days into **years, weeks, and days** using division and the modulo operator.
- Developed a **leap year checker** using mathematical logic.

### User Interaction & Program Flow
- **ATM Simulator:** Built a fully interactive program simulating an ATM. This project utilized:
  - A continuous `while` loop to keep the program running.
  - `input()` to prompt the user for a PIN and menu selections.
  - Nested `if/else` statements to handle deposits, withdrawals, and balance checks.
  - Verification logic (e.g., ensuring withdrawal amounts are multiples of 10 and do not exceed the current balance).
  - Functions to separate the menu options for cleaner code.
