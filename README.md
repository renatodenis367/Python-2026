# Python Fundamentals & Logic

## Project Overview
This repository contains a collection of foundational Python programming exercises focused on core programming logic, algorithmic thinking, and interactive user experiences. The project demonstrates the ability to translate real-world logic into functional, modular code using standard Python syntax.

## Core Skills Demonstrated

### 1. Variables, I/O, and Type Casting
- Declared and assigned variables to manage program state.
- Utilized `print()` for formatted output and `input()` for dynamic user interaction.
- Applied **type casting** (e.g., `int()`, `float()`) to convert and validate user inputs for mathematical operations.

### 2. Control Flow and Logic
- Implemented `if`, `elif`, and `else` statements to control program flow and handle conditional logic.
- Used comparison and modulo operators (`==`, `%`) to evaluate data and make decisions.

### 3. Loops
- Utilized `for` loops to iterate through sequences, ranges, and collections.
- Implemented `while` loops for continuous execution until specific conditions are met, such as menu navigation and PIN validation.

### 4. Functions
- Created reusable blocks of code using `def` to perform specific tasks, ensuring clean, modular, and maintainable architecture.

---

## Practical Applications & Algorithms

### Algorithmic Logic
- **FizzBuzz:** Implemented the classic programming challenge using a `for` loop and `if/elif/else` logic to check for divisibility by 3 and 5.
- **Palindrome Checker:** Developed logic to reverse strings and compare them to the original input.
- **Prime Number Checker:** Used loops and conditional logic to determine if a number has any divisors other than 1 and itself.
- **Leap Year Calculator:** Applied mathematical logic to determine if a given year is a leap year.

### Interactive Console Application
- **ATM Simulator:** Built a fully interactive console application that simulates an ATM interface. Key features include:
  - A continuous `while` loop to keep the program running.
  - `input()` prompts for user PIN and menu selections.
  - Nested `if/else` statements to handle deposits, withdrawals, and balance checks.
  - Transaction verification (e.g., ensuring withdrawal amounts are multiples of 10 and do not exceed the current balance).
  - Modular functions to separate menu options and handle transactions cleanly.

## Learning Outcomes
- Developed a strong grasp of Python syntax and core programming concepts.
- Successfully translated real-world logic into functional, interactive scripts.
- Gained confidence in writing, testing, and debugging Python code in a modular format.
